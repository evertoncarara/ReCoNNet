Create a new implementation (ReCoNNet or Hardwired)
---------------------------------------------------
    - After generate parameters with Cyberdyne script, copy the following files/directory
    into the corresponding VHDL directory (ReCoNNet or Hardwired)
        - raw directory     --> VHDL/ReCoNNet/sim or VHDL/Hardwired/sim 
        - CNN_params.txt    --> VHDL/ReCoNNet/sim
        - SkyNet_pkg.vhd    --> VHDL/Hardwired/src
        - ReCoNNet_pkg.vhd  --> VHDL/ReCoNNet/src
        


Create a new ReCoNNet config
----------------------------
    - After generate parameters with Cyberdyne script, copy the following file/directory
    into the ReCoNNet VHDL directory
        - raw directory     --> VHDL/ReCoNNet/sim
        - CNN_params.txt    --> VHDL/ReCoNNet/sim
